Token Radar ranks 198 pre-token protocols by implied value — TVL, seven-day growth, how long each has run with no token, and how many chains it runs on — with a seven-step farm plan for each, on a sealed 2026-11-14 DefiLlama snapshot. The board covers all 40 watchlist protocols plus 158 early finds below the $50M floor, and sets the live-token protocols aside at their market values instead of mixing them into the ranking.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input ../input/snapshot.json
```
